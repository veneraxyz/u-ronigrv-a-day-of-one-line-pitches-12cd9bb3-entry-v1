One sentence, written for a friend who has never coded, to convince them to let an
AI agent build their first app idea on make.fun: it names the idea they've been
carrying around, promises a real working version they can try today, and makes
saying yes feel easy — no coding needed, nothing to lose if the first version
isn't quite right yet.

## Run

```sh
node main.ts
```

This writes the pitch to `output/entry.txt` (one sentence, under 240 characters).
